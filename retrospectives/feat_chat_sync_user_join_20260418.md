# 🚀 feat/fix: 채팅 정합성 최적화 및 사용자 가입/탈퇴 프로세스 고도화 (2026-04-18)

## 📌 개요
오늘 작업은 Pandytalk 앱의 사용자 경험(UX)과 데이터 정합성을 한 단계 더 높은 수준으로 끌어올리는 데 집중했습니다. 
채팅방 진입 시의 시각적 노이즈(깜빡임)를 제거하고, 회원가입 및 탈퇴 시 발생할 수 있는 데이터 레이스 컨디션과 보안 이슈를 해결하였습니다.

## ✨ 주요 변경 사항

### 1. 채팅방 동기화 최적화 (Flickerless Sync)
*   **`queryKey` 안정화**: `useChatMessagesInfinite` 훅의 쿼리 키에서 `serverLastSeq`를 제거하여, 서버 상태가 나중에 업데이트되더라도 화면이 리셋되지 않도록 수정했습니다.
*   **`useEffect`를 통한 정합성 보장**: `serverLastSeq`가 가용한 시점에만 `refetch()`를 실행하여, 사용자가 느끼는 시각적 깜빡임 없이 로컬 데이터를 서버 데이터로 자연스럽게 덮어씌웁니다.

### 2. 멀티 이미지 뷰어 시각적 개선
*   **`useMemo` 활용**: `MultiImageViewer` 내에서 이미지 소스 배열의 참조값을 고정함으로써, 이미지 전환 시 뷰어가 초기화되는 현상을 수정했습니다.
*   **훅 호출 순서(Rules of Hooks) 준수**: 린트 오류를 발생시켰던 조건부 훅 호출 문제를 해결하여 렌더링 안정성을 확보했습니다.

### 3. 회원가입 프로세스 리팩토링 (`useUserJoinScreen`)
*   **가입 후 로그인 유지**: 가입 즉시 로그아웃되던 기존 방식을 변경하여, 유저가 바로 앱에 진입할 수 있게 하여 리플레이를 방지했습니다.
*   **데이터 동기화 지연 해결**: Firebase Auth와 Firestore 문서 생성 사이의 시간차로 내비게이션이 멈추는 문제를 `dispatch(fetchUserById)` 강제 호출을 통해 해결했습니다.

### 4. '완전 탈퇴' 기능 구현
*   **Firestore 데이터 정리**: 단순히 Auth 계정만 지우는 것이 아니라, `deleteProfile` 함수를 통해 Firestore 내의 유저 프로필까지 완전히 삭제하도록 개선했습니다.
*   **보안 에러 핸들링**: `auth/requires-recent-login` 에러 발생 시 사용자에게 재로그인 안내를 제공하여 보안 가이드라인을 준수했습니다.

## 🛠️ 기술적 의의
*   **UX 완성도**: 로컬 우선 노출(Offline-First) 전략과 부드러운 서버 동기화를 결합하여 네트워크 상태에 관계없이 일관된 채팅 경험을 제공합니다.
*   **데이터 무결성**: 탈퇴 시 유령 데이터(Ghost Data)가 남지 않도록 설계하여, 향후 동일 이메일 재가입 시에도 데이터 충돌이 발생하지 않는 구조를 확립했습니다.
*   **코드 품질**: 전역 내비게이션(`RootNavigation`)에 `dispatch` 방식을 도입하여 중첩된 내비게이터 상황에서도 정확한 화면 이동을 보장합니다.
