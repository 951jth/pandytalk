파이어베이스 서비스별 비용 체계 요약 (서울 리전 기준 $1 = 1,350원 환산)

1. Cloud Firestore (데이터베이스)
---------------------------------------------------------------
- 무료 할당량 (매일): 읽기 5만건, 쓰기 2만건, 삭제 2만건, 저장 1GB
- 추가 읽기 (10만건당): 약 81원 ($0.06)
- 추가 쓰기 (10만건당): 약 243원 ($0.18)
- 추가 삭제 (10만건당): 약 27원 ($0.02)
- 데이터 저장 (1GB당/월): 약 243원 ($0.18)

※ 팁: 1달러($1)면 무려 167만 건의 데이터를 읽을 수 있는 가성비 좋은 구조입니다. 


2. Cloud Functions (서버 로직/배치)
---------------------------------------------------------------
- 호출 횟수 무료 (매월): 200만 회
- 컴퓨팅 타임 무료 (매월): 40만 GB-초 (메모리 사용량 * 시간)
- 무료 할당량 초과 시: 100만 회당 약 540원 ($0.40) + 컴퓨팅 사용량 비례

※ 팁: 주기가 긴 배치나 가벼운 로직은 사실상 운영 내내 무료 티어 내에서 해결 가능합니다.


3. Cloud Storage (이미지/프로필/영상)
---------------------------------------------------------------
- 저장 용량 무료 (매월): 5 GB
- 다운로드 트래픽 무료 (매일): 1 GB
- 추가 저장 (1GB당/월): 약 35원 ($0.026)
- 추가 다운로드 (1GB당): 약 162원 ($0.12)
- 업로드 연산 (1만회당): 약 68원 ($0.05)

※ 팁: 유저 이미지를 업로드할 때 가로세로 크기를 최적화해서 올리는 습관이 지갑을 지켜줍니다.


4. Cloud Messaging (FCM/푸시알림)
---------------------------------------------------------------
- 횟수 제한 없음: 100% 무료 (구글의 가장 혜상적인 서비스 중 하나)


💡 비용 최적화 최종 전략 💡
- 'onSnapshot' 리스너 최소화: 데이터 변경 감지가 실시간으로 필요할 때만 선별적으로 사용.
- 스켈레톤 UI & 캐시 활용: 불필요한 데이터 재조회를 막기 위해 한 번 불러온 유저 정보는 메모리에 보관.
- 주기적인 배치(Job) 최적화: 유저 상태 정리 등은 사람이 적은 시간대나 긴 주기로 돌리도록 설계 (완료).
- 이미지 최적화: 프로필은 200x200 수준, 메시지 전송용은 800px 수준으로 줄여서 업로드 권장.
