// turbo-all
사용자가 "푸쉬해줘", "커밋해줘", "push" 또는 `/push` 등의 키워드로 작업을 요청하면 다음 단계를 자동으로 수행하세요:

1. 최근 대화 내역(작업 내역)과 변경된 파일 내용을 분석하여 의도가 잘 담긴 적절한 커밋 메시지를 한글로 작성합니다. (Conventional Commits 스타일 사용. 예: `fix: ...`, `feat: ...`)
   - 만약 변경 사항이 너무 많으면 핵심적인 내용만 요약하여 작성합니다.
2. 루트 디렉토리에서 다음 명령어를 하나로 묶어 실행합니다:
   `git add . && git commit -m "생성된 커밋 메시지" && git push`
   - 실행 시 `WaitMsBeforeAsync`를 적절히 설정하여 명령이 진행 중임을 사용자가 알 수 있게 하거나, 백그라운드에서 실행하고 상태를 주기적으로 보고합니다.
3. 작업이 완료되면 수행된 커밋 메시지와 함께 완료되었음을 사용자에게 보고합니다. 만약 오류가 발생하면 즉시 사용자에게 알리고 조치를 요청합니다.
