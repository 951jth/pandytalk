사용자가 "푸쉬해줘", "커밋해줘", "push" 또는 `/push` 등의 키워드로 작업을 요청하면 다음 단계를 자동으로 수행하세요:

1. 프로젝트의 루트 디렉토리(`c:\Users\CSH\Projects\pandytalk`)로 이동하여 변경된 파일 목록(`git status`)을 확인합니다.
2. 변경된 파일 목록을 바탕으로 최근 대화 내역(작업 내역)을 분석하여 의도가 잘 담긴 적절한 커밋 메시지를 한글로 작성합니다. (Conventional Commits 스타일 사용. 예: `fix: ...`, `feat: ...`)
// turbo-all
3. 위에서 생성한 메시지를 바탕으로 루트 디렉토리에서 반드시 다음 명령어를 하나로 묶어 실행합니다:
   `git add . && git commit -m "생성된 커밋 메시지" && git push`
4. 배치가 성공적으로 완료되면 수행된 커밋 메시지와 함께 완료되었음을 사용자에게 보고합니다.
