---
description: 사용자가 "푸쉬해줘", "커밋해줘", "push" 또는 `/push` 등의 키워드로 작업을 요청할 때 처리 방법
---

사용자가 작업을 요청하면 직접 명령을 실행하는 대신, 다음 단계를 수행하여 사용자가 직접 실행할 수 있도록 안내하세요:

1. **변경 사항 분석**: 최근 작업 내역과 파일 변경 사항을 분석하여 작업의 의도가 잘 담긴 커밋 메시지를 작성합니다.
   - **Conventional Commits** 스타일 사용 (예: `feat: ...`, `fix: ...`, `style: ...`, `docs: ...`)
   - 메시지는 **한글**로 작성합니다.

2. **명령어 생성**: 사용자가 터미널에 복사해서 바로 붙여넣을 수 있도록 다음 형식의 통합 명령어를 생성합니다.
   - 형식: `git add . ; git commit -m "작성된 커밋 메시지" ; git push`
   - Windows 환경(PowerShell)을 고려하여 `&&` 대신 `;`을 기본으로 사용하되, 상황에 따라 안내합니다.

3. **사용자 가이드**: 
   - 생성된 명령어를 마크다운 코드 블록으로 제시합니다.
   - "위 명령어를 복사하여 터미널에서 실행해 주세요."와 같은 안내 문구를 함께 출력합니다.
   - 만약 커밋 메시지에 대해 수정이 필요하다면 말씀해 달라는 메시지를 덧붙입니다.

**주의사항**: 직접 `run_command`를 통해 `git push`를 시도하지 마세요. 반드시 사용자의 최종 확인과 실행을 거치도록 합니다.
